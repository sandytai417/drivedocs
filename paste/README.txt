DriveDocs 可複製原始檔（v260813s）
================================
每個 *.txt 就是 Apps Script 要貼上的完整內容。
檔名去掉 .txt 就是 Apps Script 裡的檔名。

例如：App.html.txt → 整份覆蓋「App」
      Config.gs.txt → 整份覆蓋「Config」

用法：開啟該 .txt → 全選 → 複製 → 貼進 Apps Script 同名檔 → 部署新版本。
必須一起覆蓋的檔（資料夾總覽／保單分類卡）：
  App.html.txt
  Index.html.txt
  Config.gs.txt
  DriveFolder.gs.txt
  DriveService.gs.txt
  DocumentService.gs.txt
  Setting.gs.txt
  DashboardService.gs.txt
  DemoData.gs.txt
